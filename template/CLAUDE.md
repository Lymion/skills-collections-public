## UI work

For any UI work (new screens, components, restyles, reviews), use these skills:

- **ui-ux-pro-max**: pick the design system with the **"Apple Native Experience"** style.
- **apple-design** and **emil-design-eng** (Emil Kowalski): layout, motion and polish.
- **ui-elevate**: improve existing UI in focused passes.
- **scratch**: prototype a new screen in one `scratch.html` before building it for real.

Keep every screen simple and intuitive: fewer elements, clear hierarchy,
platform conventions over novelty, and motion only where it helps.
