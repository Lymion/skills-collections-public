# haykal-skills

Haykal's public Claude Code skills in one plugin: UI/UX design and
animation, marketing, context engineering, Remotion video, writing and math
tutorial solutions.

Install:

```
/plugin marketplace add Lymion/skills-collections-public
/plugin install haykal-skills@haykal-public
```

The `skills/` folder is generated by `scripts/build.sh` from `skills-src/` at
the repository root. Edit skills there, not here. See the repository README for
the full skill list and CREDITS.md for third-party licenses.
